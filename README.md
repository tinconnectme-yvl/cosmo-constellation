# 🛰️ COSMO-CONSTELLATION // Сервис проектирования спутниковой группировки
### Проект команды «Точка Лагранжа» на КосмоХакатон 2026 (Кейс 2)

Интерактивный программный комплекс и веб-сервис для моделирования орбитальной группировки (48 спутников, $h=550$ км, 3 плоскости), динамической маршрутизации трафика через межспутниковые линии (ISL) до Мурманского шлюза (`G_MUR`) и анализа непрерывности связи в арктических терминалах (`C65`, `C70`, `C72`).

---

## ⚡ Быстрый старт (Quick Start)

### Вариант 1: Запуск через Docker Compose (Рекомендуемый для жюри и VDS)

Развертывание одной командой без необходимости устанавливать Python или Node.js:

```bash
cd solution
docker compose up --build -d
```

Сервис будет сразу доступен в браузере по адресу:
👉 **`http://localhost:8000`**

Проверка здоровья сервиса:
```bash
curl http://localhost:8000/api/health
```

Остановка:
```bash
docker compose down
```

---

### Вариант 2: Локальный запуск на Python (Windows / Linux / macOS)

**Требования:** Python 3.10 или новее.

1. Перейдите в каталог бэкенда:
   ```bash
   cd solution/backend
   ```
2. Создайте и активируйте виртуальное окружение:
   ```bash
   # Windows PowerShell:
   python -m venv venv
   .\venv\Scripts\Activate.ps1

   # Linux / macOS:
   python3 -m venv venv
   source venv/bin/activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите автоматические тесты:
   ```bash
   pytest tests/
   ```
5. Запустите сервер:
   ```bash
   uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```
6. Откройте в браузере: **`http://localhost:8000`**.

## 🧭 Возможности веб-интерфейса (Mission Control)

1. **Интерактивная карта орбит на Canvas:**
   * Режим фокуса на Арктику ($40^\circ..88^\circ$N) и глобальный вид Земли.
   * Отображение 48 спутников в 3 орбитальных плоскостях (P1 — циан, P2 — янтарь, P3 — фиолетовый).
   * Динамические межспутниковые линии связи (ISL $< 3000$ км, без затенения Землей).
   * **Активный сквозной маршрут передачи данных:** анимированный световой луч от терминала через цепочку спутников в Мурманск.
   * **Интерактивная авария («Chaos Monkey»):** клик по любому спутнику на карте отключает его с мгновенным пересчетом маршрута в реальном времени.

2. **24-часовой таймлайн:**
   * Ползунок времени от 00:00:00 до 23:58:00 (шаг 120 с).
   * Воспроизведение Play/Pause, скорости 1x, 5x, 15x, 60x.
   * Диаграмма доступности (Gantt timeline bar) с цветовой индикацией окон связи и перерывов.
   * Кнопка «След. сбой» для быстрой перемотки к аварийным окнам.

3. **Конфигуратор группировки:**
   * Выбор очереди развертывания: 1 очередь (16 апп.), 2 очередь (32 апп.), 3 очередь (48 апп.).
   * Регулировка углов плоскостей RAAN ($\Omega$) и Phase ($\Delta u$).
   * Стратегии маршрутизации: Min Hops (BFS) и Min Distance (Dijkstra).

4. **Экран сравнения сценариев (Side-by-Side):**
   * Сопоставление двух конфигураций в одной таблице с расчетом дельты доступности, перерывов и хопов.

5. **Валидатор и загрузка файлов:**
   * Drag-and-drop загрузка любого JSON сценария схемы `cosmo-A-1.0` с информативными сообщениями об ошибках.
   * Экспорт стандартного результата `cosmo-A-result-1.0`.

## 🔌 Спецификация REST API

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/api/health` | Проверка работоспособности сервиса |
| `GET` | `/api/scenarios` | Список предустановленных сценариев |
| `GET` | `/api/scenarios/{id}` | Получение JSON сценария по идентификатору |
| `POST` | `/api/scenarios/upload` | Загрузка внешнего файла сценария с валидацией |
| `POST` | `/api/simulate` | Полный расчет суточной динамики (720 шагов) и метрик |
| `GET` | `/api/snapshot/{t_s}` | Моментальный снимок графа, спутников и путей в момент `t_s` |
| `POST` | `/api/compare` | Сопоставление двух конфигураций (Side-by-side) |
| `POST` | `/api/export` | Выгрузка стандартного JSON отчета `cosmo-A-result-1.0` |
