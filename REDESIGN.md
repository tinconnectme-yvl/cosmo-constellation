# ПОЛЮС — редизайн интерфейса

Обновлён frontend и его копия backend/app/static. Расчётный backend и исходные сценарии сохранены.

## Демонстрация
1. На главной дождитесь расчёта: показатели и графики поступают из /api/simulate.
2. Зафиксируйте вариант для сравнения.
3. Откройте орбитальную сцену. По умолчанию выбран 3D-глобус.
4. Переключите 48 / 16 спутников, измените высоту или параметры плоскостей. Дождитесь пересчёта.
5. Выберите терминал и отключите спутник активного маршрута. Восстановите сеть.
6. Вернитесь в обзор и сравните доступность и максимальный перерыв с зафиксированным вариантом.
7. Дополнительные сценарии, вторая очередь (32 аппарата), алгоритм маршрутизации и индивидуальные углы плоскостей доступны в «Параметры и сценарии».

Запуск сервера — по основному README проекта. Сервер раздаёт backend/app/static; при последующих правках frontend синхронизируйте обе папки. Открытие index.html напрямую не заменяет запуск API.

## Графика и производительность
Земля: локальная текстура 2048px, WebGL-шейдер, атмосферное рассеяние в декоративной модели освещения. Это не астрономически точная модель терминатора или облачности. При отсутствии WebGL остаётся исходная векторная Земля.
Источник текстуры: https://raw.githubusercontent.com/mrdoob/three.js/dev/examples/textures/planets/earth_atmos_2048.jpg (three.js examples).
Никаких загрузок текстуры или библиотек из CDN во время работы. Системный шрифт.
Поверхность Земли кэшируется до изменения ракурса; плотность пикселей ограничена 1.5; временная диаграмма обновляется не чаще 10 раз в секунду. На главной и при скрытии вкладки воспроизведение остановлено. Скорости 1×–600× соответствуют заявленному множителю времени.
На телефоне панели раскрываются кнопками; поддержаны вращение касанием, pinch zoom, отдельные кнопки масштаба и доступный ползунок времени.

## Данные
Графики показывают результат расчётной сетки, а непрерывные позиции спутников интерполируются аналитически. Средняя задержка использует поле avg_latency_ms исходного API; не переименована в RTT без проверки определения модуля.
Из интерфейса удалены фиксированные обещания 100% доступности, 0 мс восстановления, экономического эффекта и ссылка на неподтверждённый ГОСТ.
Сравнение зафиксированного варианта хранится только до перезагрузки страницы и относится к Урал-Северу.

## Проверено
Синтаксис всех JS-модулей, локальная загрузка API и ассетов, отображение трёх проекций, первая очередь (16 аппаратов), показатели и графики из модели, размеры 390×844 и 1440×900. Проверка браузера не выявила ошибок JavaScript. Производительность на всех устройствах не гарантируется: отдельного аппаратного FPS-бенчмарка не проводилось.
